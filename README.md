# AI 工作流提示词

> 两套可直接复制的 AI 视频工作流提示词。交给支持本地文件操作的 AI 编程 Agent，就能从零搭建对应工作流。

## 两套工作流

| 工作流 | 解决什么 | 包含提示词 |
|---|---|---|
| **A. AI 数字人视频生产** | 输入一个主题，自主研究、写稿、生成配音与数字人、合成并交付一条可发布视频 | 初始化项目 + 生成视频 |
| **B. 实拍口播自动剪辑** | 拿到原始实拍口播素材，自动收紧节奏——剪气口、剪废话，保留情绪和信息 | 实拍口播剪辑 |

两套工作流相互独立：A 从零生成数字人视频，B 剪辑你已经拍好的真人素材。按需选用，不强制一起用。

---

## 工作流 A：AI 数字人视频生产

从主题到成片的全流程，使用两份提示词配合完成。

### 三步开始

1. **搭建项目**：复制 [项目初始化提示词](prompts/initialize-video-agent.md)，交给 AI 编程 Agent，指定一个空文件夹作为项目根目录。Agent 会创建项目规则、目录结构、品牌模板、环境变量模板、视频工作流和质检规则。这个阶段不生成视频、不调用付费服务。
2. **配置服务**：根据实际采用的链路准备账号或 API（大模型、数字人、声音、素材、本地工具）。真实密钥只写入本地 `.env`，不要放进提示词、代码、日志或 GitHub。
3. **生成视频**：打开 [视频生产提示词](prompts/video-agent-generic.md)，填写主题、目标观众、平台、时长和画面比例，交给已初始化的项目 Agent。最终交付应当是经过真实渲染和质量检查的 MP4，而不只是脚本或制作方案。

### 工作流

```text
输入主题
  -> 研究与事实核验
  -> 品牌分析、脚本与分镜
  -> 配音与数字人片段
  -> 视觉素材与视频合成
  -> 真实渲染和质量检查
  -> 修复问题并输出 MP4
```

详细说明见 [docs/WORKFLOW.md](docs/WORKFLOW.md)。

## 工作流 B：实拍口播自动剪辑

拿到原始实拍口播素材，AI 完成从素材理解到粗剪成片的后期工作。核心价值一句话：**自动收紧节奏——剪掉气口和废话，保留情绪和信息**。未经收紧直接交付视为剪辑未完成。

### 环境安装

1. **Video Use**（对话式视频剪辑引擎）：clone 到稳定路径，`uv sync` 或 `pip install -e .` 装依赖（requests / librosa / matplotlib / pillow / numpy）。
2. **ffmpeg + ffprobe**：硬性依赖，负责素材探测、切片无损拼接、淡入淡出。
3. **ElevenLabs Scribe API Key**：写入 `.env`，提供逐字级时间戳、说话人分离、filler 标注。付费服务——首次转录未缓存素材前必须告知用户素材数量、总时长并等待确认，项目搭建/环境验证阶段禁止调用。
4. 把 skill 注册到当前 Agent（symlink 整个目录，helpers 要和 SKILL.md 同级）。

### 核心流程

```text
导入检查 -> 逐字转录 -> 提出剪辑策略 -> [用户确认] -> 执行粗剪 -> 切点自检 -> 渲染交付
```

核心规则：剪气口与剪废话。

- **必须删**：绕弯铺垫、同义反复、口头冗余；无情绪作用的句间停顿和找词停顿；口误、假开头、完全重复的 take、找词失败后的长空段。判断标准——删掉这段观众失去的是信息还是只是时间？只失去时间的就删。
- **必须保留**：情绪性呼吸、强调前后的留白、笑声、叹气、反应；没有更好 take 的真实表达；置信度不足的候选（保留并标记复查）。
- **切点标准**：只能落在逐字时间戳边界、绝不在词中间切断；每边留 30–200ms 安全余量；每个片段边界加约 30ms 音频淡入淡出；不得整体变速。

完整提示词见 [prompts/talking-head-edit.md](prompts/talking-head-edit.md)。

## 使用原则

- 只使用已获得授权的数字人、声音和素材。
- 涉及新闻、数据和产品信息时，优先使用官方或第一方来源核验。
- 不要把 API Key、密码、登录状态和个人资产提交到公开仓库；密钥只写入本地 `.env`。
- 付费生成前确认服务、参数和预计费用，局部失败优先局部重做。
- 必须检查真实渲染结果，不能只检查代码或工程配置。
