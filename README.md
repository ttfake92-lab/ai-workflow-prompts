# AI Video Agent Prompts

两份可直接复制的通用提示词，帮助你从零搭建 AI 视频生产项目，并从一个主题生成完整的 AI 数字人视频。

## 三步开始

### 1. 搭建项目

复制 [项目初始化提示词](prompts/initialize-video-agent.md)，交给支持本地文件操作的 AI 编程 Agent，并指定一个空文件夹作为项目根目录。

Agent 会创建项目规则、目录结构、品牌模板、环境变量模板、视频工作流和质量检查规则。这个阶段不会生成视频，也不会调用付费服务。

### 2. 获取并配置所需服务

根据你实际采用的生产链路，准备需要的账号或 API：

- 大模型：用于研究、脚本和任务编排；
- 数字人：即梦、HeyGen 或其他已获授权的数字人服务；
- 声音：数字人平台内置音色，或独立声音生成服务；
- 图片、视频和素材服务：按内容需要选择；
- 本地工具：Node.js、Python、FFmpeg、Git 和视频合成工具。

真实密钥只写入本地 `.env`，不要放进提示词、代码、日志或 GitHub。

### 3. 复制提示词生成视频

打开 [视频生产提示词](prompts/video-agent-generic.md)，填写视频主题、目标观众、平台、时长和画面比例，然后交给已经初始化好的项目 Agent。

最终交付应当是经过真实渲染和质量检查的 MP4，而不只是脚本或制作方案。

## 两份提示词

| 提示词 | 用途 |
|---|---|
| [initialize-video-agent.md](prompts/initialize-video-agent.md) | 初始化完整的本地 AI 视频生产项目 |
| [video-agent-generic.md](prompts/video-agent-generic.md) | 自主研究、制作、质检并交付一条完整视频 |

## 工作流

```text
输入 Goal
  ↓
研究与事实核验
  ↓
品牌分析、脚本与分镜
  ↓
配音与数字人片段
  ↓
视觉素材与视频合成
  ↓
真实渲染和质量检查
  ↓
修复问题并输出 MP4
```

详细说明见 [docs/WORKFLOW.md](docs/WORKFLOW.md)。

## 使用原则

- 只使用已获得授权的数字人、声音和素材。
- 涉及新闻、数据和产品信息时，优先使用官方或第一方来源核验。
- 不要把 API Key、密码、登录状态和个人资产提交到公开仓库。
- 付费生成前确认服务、参数和预计费用，局部失败优先局部重做。
- 必须检查真实渲染结果，不能只检查代码或工程配置。
