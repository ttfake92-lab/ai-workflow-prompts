# AI 视频生产工作流

## 第一步：初始化项目

1. 新建一个空文件夹作为项目根目录。
2. 把 `prompts/initialize-video-agent.md` 交给支持本地文件操作的 AI 编程 Agent。
3. Agent 先建立 `CLAUDE.md`、`AGENTS.md` 和目录规则，再创建配置、提示词、素材、品牌、工程、输出、日志和文档目录。
4. 检查 Node.js、npm、Python、FFmpeg、Git 和视频合成环境。
5. 确认初始化阶段没有调用付费服务，也没有写入真实密钥。

完成标志：项目结构、环境变量模板、品牌模板、服务文档和质检流程已经落盘。

## 第二步：配置服务

只配置实际会使用的服务，不需要一次申请全部 API。

| 能力 | 可选方案 | 配置重点 |
|---|---|---|
| 研究与脚本 | OpenAI 或其他大模型 | 模型、额度、事实核验能力 |
| 数字人 | 即梦、HeyGen 或同类服务 | 角色授权、音色、生成模式、计费 |
| 声音 | 平台内置音色或独立声音服务 | 声音授权、语速、分段稳定性 |
| 视觉素材 | 图片生成、视频生成或素材库 | 使用权限、来源和画面比例 |
| 视频合成 | HyperFrames 或其他本地工具 | 预览、字幕、动画和 MP4 渲染 |

安全要求：

- 密钥只写入本地 `.env`；
- `.env` 必须被 Git 忽略；
- 日志只记录非敏感参数；
- 未经允许，不切换后端或产生明显额外费用；
- 不使用未经授权的形象、声音和素材。

完成标志：项目能够验证所需账号或 API，但还没有提交正式付费生成任务。

## 第三步：生成视频

1. 打开 `prompts/video-agent-generic.md`。
2. 填写主题、目标观众、发布平台、目标时长、画面比例和语言。
3. Agent 研究主题并核验事实，随后生成自然口播、字幕和分镜。
4. 按自然语义拆分口播，生成配音和数字人片段。
5. 准备与口播对应的截图、图表、图片、信息卡和动画。
6. 完成视频合成，先预览，再渲染初版。
7. 连续检查画面、声音、字幕、口型、事实、同步和文件规格。
8. 只重做出错部分，重新渲染并复查。
9. 输出最终 MP4、脚本、字幕、素材、工程、资料来源和发布文案。

完成标志：最终 MP4 可以正常播放，并通过画面、音频、事实和同步检查。

│   ├── images/

├── brand/

所有中间结果都应落盘，确保每一步可以回看、替换和单独重跑。
