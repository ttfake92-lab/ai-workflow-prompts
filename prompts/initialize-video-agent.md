# AI 视频自动生产 Agent 初始化提示词

你需要帮我初始化一个“AI 视频自动生产 Agent”本地项目，为后续实现“输入一个 Goal，自动生成完整短视频”做好基础工程准备。

本次只搭建基础设施、规则、模板和工作流，不生成视频、不调用付费 API、不提交任何生成任务。

## 一、项目目标

未来的完整流程是：

用户输入 Goal
→ 分析主题、受众、平台、时长和风格
→ 根据品牌资料与历史脚本生成口播和分镜
→ 按自然语义切分数字人口播
→ 生成数字人视频片段
→ 准备图片、动画和音乐素材
→ 自动添加字幕并完成剪辑
→ 预览和质量检查
→ 用户确认
→ 渲染 MP4
→ 复盘并更新品牌风格规范

所有中间结果必须落盘，支持回看、修改、替换和从任一步重新执行。

## 二、先建立项目规则

创建 `CLAUDE.md` 和 `AGENTS.md`，明确：

- 项目目标和完整工作流
- 文件结构与读写边界
- 素材和成片命名规则
- 品牌资料读取规则
- 即梦、Fish Audio、HeyGen、HyperFrames 和 FFmpeg 的职责
- 密钥只能从 `.env` 读取，不能写入代码、提示词和日志
- 付费生成前必须记录参数，未经允许不得提交
- 渲染前必须依次完成 lint、validate、inspect 和 preview
- 用户确认预览后才能正式渲染
- 不得跳过报错、质检或静默切换生成后端

## 三、创建项目结构

创建：

```text
video-agent/
├── config/          # 可调整的项目配置
├── prompts/         # Agent、脚本和分镜提示词
├── scripts/         # 自动化及服务调用脚本
├── assets/
│   ├── images/      # 图片素材
│   ├── audio/       # 配音和音乐
│   └── video/       # 数字人及其他视频片段
├── brand/           # 品牌、脚本和视觉规范
├── references/      # 历史脚本与参考视频
├── output/          # 最终成片
├── hyperframes/     # HyperFrames 视频工程
├── logs/            # 运行日志和历史错误
└── docs/            # 项目文档
```

为各目录制定用途、命名和清理规则。

成片统一命名为：

`output/YYYY-MM-DD_主题slug_vN.mp4`

## 四、建立品牌化系统

创建：

- `brand/brand-guide.md`
- `brand/script-style.md`
- `brand/visual-style.md`

`brand-guide.md` 包含：

- 创作者身份与经历
- 内容方向与价值主张
- 目标用户
- 选题边界
- 视频气质
- 语言风格
- 常用开场和结尾
- 视觉风格
- 禁止使用的表达和内容

`script-style.md` 用于分析 `references/` 中的历史脚本，提炼：

- 选题角度和观点立场
- 开场方式与吸引力来源
- 叙事和论证结构
- 长短句、停顿与节奏
- 口语习惯、常用表达和情绪强度
- 案例、转折、总结和行动引导方式
- 应避免的 AI 腔、套路和机械短句

新脚本要学习这些稳定规律，形成创作者自己的风格，但不得照抄原文或机械套用固定模板。每次视频复盘后，继续更新品牌指南和脚本风格规范。

口播必须像真人自然讲述。先完成连贯口播，再分别设计字幕和画面；不能为了字幕、分镜或技术限制，把完整意思拆成连续碎句。

品牌资料中无法从历史内容确定的信息标记为“待填写”，不得自行编造。

## 五、定义视频生成链路

### 默认链路：即梦数字人

即梦负责生成数字人口播片段：

- 使用浏览器中的既有登录状态
- 角色视频、音色和生成模式必须配置化，不写死个人资产
- 默认使用基础模式
- 每段口播不超过 120 个字符
- 必须按自然语义切分，不能机械截断句子
- 分段结果保存为 `digital-human-segments.json`
- 每段生成前记录角色、音色、模式、字符数、预计积分和时长
- 完成后下载到 `assets/video/<slug>/jimeng/segment-NNN.mp4`
- 检查声音、动作、口型、停顿和片段衔接
- 上传、登录、积分或生成失败时停止并报告，不得静默切换其他后端

创建 `docs/JIMENG.md`，记录完整操作流程、参数、下载规则、异常处理和日志格式。

### 备选链路：Fish Audio + HeyGen

只有用户明确同意后才能启用：

- Fish Audio 负责生成克隆配音
- HeyGen 只负责外部音频驱动的数字人画面与 lip-sync
- 不得改用 HeyGen 自带声音重新配音
- 默认语速为 `1.0x`
- 不得为了节省费用而压缩脚本、加快语速或降低质量
- API 已配置时，付费生成必须走 API，不得擅自切换免费 CLI、MCP 或浏览器方案
- 失败时停止排查，不得静默切换 ElevenLabs、系统 TTS 或其他声音服务

创建 `docs/HEYGEN.md`，说明 API、CLI、MCP 和浏览器的使用优先级、外部音频提交方式、计费规则和异常处理。

### 合成链路：HyperFrames + FFmpeg

HyperFrames 负责：

- 创建视频工程
- 组合数字人片段
- 添加字幕、图片、动画和音乐
- 制作转场和图形叠加
- 预览、检查和渲染 MP4

FFmpeg 负责：

- 转码
- 裁剪
- 音视频检查
- 抽帧
- 音频拼接和响度处理

注意：HyperFrames 是独立的本地视频合成工具，不属于 HeyGen，也不需要 HeyGen API Key。

## 六、创建环境变量模板

创建 `.env.example`，只写占位符，不填写真实值：

- `OPENAI_API_KEY`
- 其他模型接口预留项
- `HEYGEN_API_KEY`
- `HEYGEN_AVATAR_ID`
- `FISH_API_KEY`
- `FISH_VOICE_ID`
- `FISH_MODEL`
- 图片生成服务
- 视频生成服务
- 云存储
- 素材搜索
- 内容发布平台

即梦浏览器登录态、角色视频和音色不作为 API Key 保存；相关非敏感参数放入配置文件。

## 九、准备基础模板

只创建模板，不生成实际内容：

- Goal 分析模板
- 品牌化脚本模板
- 分镜表模板
- 即梦自然语义分段模板
- 字幕切分模板
- 视频工程模板
- 运行日志模板
- 质量检查清单
- 视频复盘模板

质量检查至少包括：

- 口播是否自然连贯
- 上下文衔接和停顿是否正常
- 数字人口型、动作和声音是否匹配
- 字幕是否准确、易读
- 画面是否符合品牌规范
- 音画是否同步
- 是否存在静音、黑帧、错字或素材缺失
- 是否以正常 1 倍速完整试听
- 输出时长、分辨率和文件命名是否正确

## 十、执行边界

本次不要：

- 生成脚本正文或视频
- 调用即梦、Fish Audio、HeyGen 或其他付费服务
- 填写真实密钥
- 复制他人的品牌资产、账号、音色或历史内容
- 提交生成任务
- 渲染正式成片

完成后向我报告：

1. 创建了哪些文件和目录
2. 检测到哪些工具及版本
3. 缺少哪些工具，以及安装方法
4. 哪些品牌资料等待填写
5. 哪些 API 等待配置
6. 默认即梦链路和备选 HeyGen 链路是否已正确区分
7. 下一步如何导入历史脚本并生成第一条视频
