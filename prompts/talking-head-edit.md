# 实拍口播视频自动剪辑工作流

## 目标
用户提供原始实拍口播素材,AI 完成从素材理解到粗剪成片的后期工作。核心价值只有一句话:**自动收紧节奏--剪掉气口和废话,保留情绪和信息**。未经收紧直接交付视为剪辑未完成。

## video-shotcraft地址：
https://vincentwei1021.github.io/video-shotcraft/

## 环境安装(关键项)

1. **Video Use**(对话式视频剪辑引擎):clone 到稳定路径,`uv sync` 或 `pip install -e .` 装依赖(requests / librosa / matplotlib / pillow / numpy)。
2. **ffmpeg + ffprobe**:硬性依赖,负责素材探测、切片无损拼接、淡入淡出。
3. **ElevenLabs Scribe API Key**:写入 `.env`。提供逐字级时间戳、说话人分离、filler 标注。**付费服务--首次转录未缓存素材前必须告知用户素材数量、总时长并等待确认,项目搭建/环境验证阶段禁止调用。**
4. 把 skill 注册到当前 agent(symlink 整个目录,helpers 要和 SKILL.md 同级)。

## 核心流程

```
导入检查 -> 逐字转录 -> 提出剪辑策略 -> [用户确认] -> 执行粗剪 -> 切点自检 -> 渲染交付
```

1. **导入检查**:ffprobe 检查时长/比例/帧率/音轨/HDR。原始素材保持不可变,所有派生产物只写入 `edit/`。
2. **逐字转录**:批量转录生成**逐字级**时间戳(按源文件缓存,源未变化不重转),打包成短语级 `takes_packed.md` 供阅读。按素材真实语言识别,支持中英混说,不得翻译/润色/音译原文。
3. **提出策略**:4–8 句话说明取舍、结构、预计时长、风险、低置信度项。**确认前不得执行任何剪切。**
4. **执行粗剪**:生成 EDL,按逐字边界提取片段。
5. **自检**:每个切点前后 ~1.5s 看画面与波形,1 倍速试听,最多 3 轮自动修复,超限如实报告。
6. **渲染交付**。

## 【核心】节奏收紧规则--剪气口与剪废话

### 必须删
- **废话**:绕弯铺垫、同义反复、口头冗余、三句能并一句的段落
- **气口**:无情绪作用的句间停顿、找词停顿
- 口误、已被完整重说替代的假开头、完全重复的 take、找词失败后的长空段、录制等待

**判断标准:删掉这一段,观众失去的是信息还是只是时间?--只失去时间的就删。**

### 必须保留
- **情绪性呼吸**(有情绪作用的气口不压缩,只有无情绪作用的才压缩)
- 强调前后的留白、笑声、叹气、反应
- 虽不完美但没有更好 take 的真实表达
- 置信度不足的删减候选(保留并标记复查)

### 删除理由(只能用这六类)
`filler` / `false-start` / `repeat` / `mistake` / `dead-air` / `guide-excluded`

自动删除置信度阈值 **0.85**;低于阈值的保留并标 `needsReview: true`。

## 切点技术标准(不可妥协)

- **切点只能落在逐字时间戳边界,绝不在词中间切断**
- 每个切边保留 **30–200ms 安全余量**(快节奏偏紧,情绪段偏松)--吸收 ASR 时间戳漂移
- 每个片段边界加 **约 30ms 音频淡入淡出**--避免爆音
- 视频与源音频用相同切点,音画同步
- **不得整体变速**制造节奏或凑时长
- 静音 ≥400ms 是最干净的切点候选;150–400ms 需看波形确认;<150ms 不安全(句中)
- 源文件从 0 到结尾的**每个区间必须归类为保留或删除**,禁止静默丢弃未列入计划的内容
- ASR 词级时间轴异常(单字 >1s、时间戳重叠)必须看波形确认:长音节常藏着结巴和重复

## 重跑边界
- 改剪辑范围:从 EDL -> 粗剪重跑;
- 源文件未变化:不重新转录;
- 原始素材永远不可变,任何派生产物都能删除后重新生成。
